# 全部自动路径失败后的访问指引

只在合法自动来源、官方网页发现和用户自有本地目录全部耗尽后读取本文件。

## 最终回复模板

```text
《{标准书名}》— 未找到可合法直下的完整 EPUB

已核实书目：{作者}；{年份/出版社}；ISBN {ISBN}。

自动来源：
- Gutenberg：{no_match / network_error / 地区版权不适用}
- OAPEN：{no_match / 仅 PDF / 许可缺失 / 网络错误}
- Open Library / IA：{无公开副本 / 仅可借阅 / 受限}
- Google Books：{无公版下载 / API 未配置 / 地区限制}
- 出版社/作者/机构仓储：{具体结果}

最快合法路径：
1. 借阅：{精确馆藏或 Open Library/本地图书馆 URL}
2. 购买：{出版社官方电子书 URL}
3. 馆际互借：用 ISBN {ISBN} 在 {WorldCat URL} 定位馆藏
```

## 指引要求

- 给出已确认的标准书名、作者、ISBN、版本和语言，避免用户再次搜索错误标题。
- 每条来源写具体失败原因，不写笼统的“找不到”。
- 优先给可借阅的具体馆藏页，其次出版社官方购买页，再次 WorldCat/馆际互借。
- 登录、借书证、付款、地区选择或 DRM 阅读器是用户必须完成的操作时，明确指出只需做哪一步，以及文件/图书会在哪里出现。
- 不给影子书库、破解 DRM、验证码绕过、会话 key、镜像轮换或来源不明的“手动下载”指引。

若存在合法 PDF 而用户只要 EPUB，报告 PDF 的来源和限制，但不要擅自把扫描 PDF 转成质量低下的 EPUB；可询问用户是否接受 PDF 或 OCR 转换。
