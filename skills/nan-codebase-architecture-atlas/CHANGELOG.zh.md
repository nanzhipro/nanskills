# 更新日志

## 1.0.0 - 2026-07-18

首个正式发布版本。

### 新功能

- 五阶段工作流:并行勘探(thorough 级子代理、五段式报告)→ 本体建模(词表推导)→ 视图布局 → 三级验证 → 交付
- 两层本体模型:形态原语(11 种节点形态 / 4 种线型)为协议层,kinds/relKinds 词表与实体关系为数据层,图例按实际使用自动生成
- 交互式架构大图:L1 全景 → L2 拓扑 → L3 模块内部 ×N → L4 数据流时序图(泳道),附设计原则页(含 `debt: true` 债务卡)
- 交互能力:详情抽屉(职责/关系/文件/部署/备注)、双击下钻、⌘K 全局搜索、平移缩放、URL hash 定位
- 工具链:
  - `validate_atlas_data.js`——引用完整性、字段 schema、id 字符集(`字母/数字/_/-`)强制
  - `lint_atlas_layout.js`——布局几何前置检查:节点重叠、画布越界、组框半进半出、边穿非端点节点(引擎同款贝塞尔采样)、边标签中点互叠、图例死区、视图规模超限
  - `shoot_atlas.sh`——逐视图截图;HTTP server 优先复用、PID 登记(`.atlas-server.pid`)、`--stop` 清理、启动就绪重试、`NOLEGEND=1` 收起图例
  - `build_standalone.py`——单文件离线版打包
- 引擎:OpenAI 式单色视觉系统;反向边(A↔B)扇形展开、双标签分离;`#/view?legend=0` 截图模式;连字符视图 id 路由
- 文档:SKILL.md(工作流与硬性规则)+ references 两卷(本体建模细则 / 视觉与布局规范)

### 首个实战检验
